# 3. Access and tokens

**Status:** Draft for approval  
**Date:** 2026-11-07  
**Source:** Phase 1 Requirements & Planning v1.0

| ID | Requirement |
| --- | --- |
| AC-01 | Verified sign-in; server-side user identity and access enforcement. |
| AC-02 | Three free successfully completed research jobs per user. |
| AC-03 | One multi-stock submitted research job = one request; retries and failed jobs do not count. |
| AC-04 | After three free jobs, show Enter Token / Request Token prompt. |
| AC-05 | Valid active token = unlimited research requests until expiration or revocation. |
| AC-06 | Admin issues, approves, revokes and expires tokens; token requests tracked. |
| AC-07 | Store token hashes, not plaintext; validate and bind tokens securely server-side. |
| AC-08 | Show free remaining count or Unlimited Access; apply reasonable abuse/API controls. |
