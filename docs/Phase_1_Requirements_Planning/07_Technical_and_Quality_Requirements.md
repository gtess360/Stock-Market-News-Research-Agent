# 7. Technology and quality

**Status:** Draft for approval  
**Date:** 2026-11-07  
**Source:** Phase 1 Requirements & Planning v1.0

| Area | Proposed standard |
| --- | --- |
| Backend | Python, LangGraph, OpenAI API. |
| Frontend | Streamlit; Plotly for interactive charts. |
| Storage | SQLite initially; PostgreSQL migration path. |
| Data providers | Choose news and price APIs in Phase 2 after evaluating coverage, price, terms and limits. |
| Testing | Pytest, mocks, integration tests and agent evaluation. |
| Security | Authentication, access checks, secure secrets, audit logs and safe token handling. |
| Reliability | Retries, timeouts, caching, deduplication, rate limits and honest partial results. |
| Environment | Separate .venv; Git/GitHub; deployment documentation. |
