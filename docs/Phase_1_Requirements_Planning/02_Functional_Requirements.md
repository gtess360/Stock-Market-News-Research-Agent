# 2. Functional requirements

**Status:** Draft for approval  
**Date:** 2026-11-07  
**Source:** Phase 1 Requirements & Planning v1.0

| ID | Feature | Acceptance expectation |
| --- | --- | --- |
| FR-01 | Multi-stock selection | Search, select and remove multiple valid ticker symbols. |
| FR-02 | Shared historical timeline | Today, 7D, 30D, 90D, custom date range; persists across tabs. |
| FR-03 | Stock News tab | Dated articles, publisher/source links, summaries, chronology. |
| FR-04 | Sentiment Research tab | Per-stock positive/negative/neutral/mixed assessment with evidence. |
| FR-05 | Forward outlook | 1/7/30/90-day horizon; catalysts, risks and scenarios. |
| FR-06 | Source verification | Check dates, duplicates and corroboration; disclose unverified claims. |
| FR-07 | Market data | Historical prices, changes, volume and timestamp/latency disclosure. |
| FR-08 | Comparisons | Compare selected stocks with clearly attributed findings. |
| FR-09 | Agent workflow | Plan steps, choose tools, verify outputs and handle failures. |
| FR-10 | Research reports | Structured cited report with as-of time and export. |
| FR-11 | History | Store and retrieve user-owned past reports. |
| FR-12 | Follow-up | Ask questions grounded in current saved research. |
| FR-13 | Failures | Invalid tickers, unavailable news, API failures and partial results. |
| FR-14 | Freshness | Show retrieval time, article publication date and market-data delay. |
